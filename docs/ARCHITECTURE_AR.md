# الهيكلية المعمارية لمنصة مسابقة التيسير الخيرية لحفظة القرآن الكريم
## Architecture Documentation — Al-Tayseer Quran Competition Platform

---

## 1. نظرة عامة على الهيكلية (High-Level Overview)

تم تصميم المنظومة بنمط **Full-Stack Dual-Engine Architecture**، يجمع بين:
1. **واجهة أمامية تفاعلية حديثة (React 19 + TypeScript + Tailwind CSS v4):**
   - مصممة أصلاً باللغة العربية مع دعم كامل للاتجاه من اليمين لليسار (`dir="rtl"`).
   - توفر تجربة تسجيل سلسة وسريعة بدون الحاجة لإنشاء حسابات من قبل المتسابقين.
   - تتضمن لوحة تحكم إدارية خاصة باللجنة المنظمة.
2. **خادم Node.js / Express متقدم (`server.ts`):**
   - مسؤول عن معالجة طلبات التسجيل وتطبيق الفحص والتحقق الصارم من صحة الأرقام القومية المصرية وأرقام الهواتف.
   - يدير مفاتيح عدم التكرار (Idempotency Fingerprinting) لمنع تكرار التسجيل أو استمارات الـ PDF.
   - يوفر حماية أمنية مشددة للوحة الإدارة بالاعتماد على القائمة البيضاء (`ADMIN_EMAILS`) ومفاتيح التشفير.
3. **جسر التكامل مع Google Workspace (`apps-script/Code.gs`):**
   - يعمل مباشرة داخل بيئة Google السحابية باسم مالك الموارد (Resource Owner).
   - يتصل بالموارد الأصلية الثلاثة المعتمدة دون الحاجة لإنشاء شيتات أو قوالب جديدة.
   - يولد ملفات PDF مباشرة داخل المجلدات المخصصة لكل مستوى حفظ في Google Drive.

## 2. مخطط تدفق البيانات (Data Flow Diagram)

```
[ الزائر / المتسابق ]
        │
        ▼ (1) ملء البيانات وتأكيد التسجيل
[ الواجهة الأمامية React (Client) ]
        │
        ▼ (2) POST /api/registrations (مع التحقق ومنع التكرار)
[ خادم Express Backend ]
   ├── التحقق من الرقم القومي (14 رقماً)
   ├── حساب السن الدقيق باليوم والشهر
   ├── توليد البصمة المشفرة (Fingerprint)
   └── استدعاء جسر التكامل (Apps Script Bridge)
        │
        ▼ (3) POST action: submitRegistration (مشفر بمفتاح APPS_SCRIPT_SECRET)
[ Google Apps Script Web App (Code.gs) ]
   ├── قفل التزامن (LockService) لمنع تصادم أرقام الطلبات
   ├── فتح الشيت المعتمد (1H4gs2Ozcj3EPSoaGM7zR6mjIjdvhzNDhZIHwNMUnNGY)
   ├── التحقق من عدم وجود الرقم القومي مسبقاً
   ├── حساب رقم المتسابق التسلسلي داخل المستوى (001, 002...)
   ├── كتابة السطر في ورقة "Form Responses 1" (الأعمدة A إلى Q)
   ├── نسخ قالب Google Docs (1dcQv657tIeuXWz2HsAt-fVzoXsJISW0EY13NEWscpj0)
   ├── استبدال الحقول السبعة (name, phone, birth, age, teacher, level, national)
   ├── حفظ وإغلاق المستند (doc.saveAndClose())
   ├── التحويل إلى PDF بحجم غير صفري
   ├── الحفظ داخل مجلد المستوى في Google Drive (1Z-mBJ639S2j4uj7LRvHfVlZ43YoQ99DY)
   └── تحديث رابط الملف وحالة PDF في الشيت
        │
        ▼ (4) استجابة النجاح
[ بطاقة المتسابق الرسمية القابلة للطباعة + إشعار لوحة الإدارة ]
```

## 4. الحقول المستبدلة في قالب Google Docs

| الحقل في القالب | العمود في Google Sheets | الوصف |
|---|---|---|
| `{{name}}` | الاسم رباعي (عمود B) | الاسم الكامل للمتسابق |
| `{{phone}}` | رقم الموبايل (عمود C) | رقم هاتف المتسابق أو ولي أمره |
| `{{birth}}` | تاريخ الميلاد (عمود H) | تاريخ ميلاد المتسابق بصيغة YYYY-MM-DD |
| `{{age}}` | السن (عمود G) | السن المحسوب دقيقاً بالسنوات والأشهر |
| `{{teacher}}` | اسم المحفظ (عمود D) | اسم الشيخ أو المحفظ المشرف |
| `{{level}}` | مقدار الحفظ (عمود E) | مستوى الحفظ المشترك به |
| `{{national}}` | الرقم القومي (عمود F) | الرقم القومي المكون من 14 رقماً |

## 5. هيكلية أعمدة جدول البيانات (Google Sheets Columns)

تم الحفاظ الكامل على الأعمدة الأصلية (A إلى I)، وتمت إضافة الأعمدة التوسعية (J إلى Q) مرة واحدة تلقائياً:

- **A:** `Timestamp` (تاريخ ووقت التسجيل)
- **B:** `الاسم رباعي`
- **C:** `رقم الموبايل`
- **D:** `اسم المحفظ`
- **E:** `مقدار الحفظ`
- **F:** `الرقم القومي`
- **G:** `السن`
- **H:** `تاريخ الميلاد`
- **I:** `رابط الملف` (رابط PDF المباشر في Google Drive)
- **J:** `رقم الطلب` (مثل: `QRC-2026-00001`)
- **K:** `حالة التسجيل` (جديد / قيد المراجعة / مقبول / مكتمل / مرفوض)
- **L:** `حالة PDF` (جاهز / قيد المعالجة / بحاجة للتحديث / فشل)
- **M:** `PDF File ID` (معرف الملف في Google Drive)
- **N:** `تاريخ إنشاء PDF`
- **O:** `ملاحظات الإدارة`
- **P:** `Registration Fingerprint` (بصمة التكرار المشفرة)
- **Q:** `رقم المتسابق داخل المستوى` (001, 002...)

## 6. إجراءات الحماية والأمان (Security & Data Protection)

1. **حجب الأرقام القومية:** في الجداول العامة وقوائم المتسابقين، يتم إخفاء الأرقام القومية تلقائياً وعرض الصيغة المقنعة (مثل: `3040******4567`). لا يظهر الرقم كاملاً إلا في شاشة التفاصيل الخاصة بالمسؤول المصرح له.
2. **التحقق من البريد المعتمد:** خادم النظام يرفض أي استدعاء للوحة الإدارة ما لم يكن مصدره بريداً معتمداً في القائمة البيضاء (`ADMIN_EMAILS` متضمناً `shahatmahmoud579@gmail.com`).
3. **تشفير الاتصال بالجسر:** يتم حماية كود Google Apps Script بمفتاح سري (`APPS_SCRIPT_SECRET`) يتم تمريره في رأس الطلب لمنع أي استدعاء عشوائي خارجي.
